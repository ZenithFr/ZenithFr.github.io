# Visual Design System: Monochromatic Brutalist Glitch Collage

## 1. Aesthetic Identity & Style Definition
**Core Concept:** A digital breakdown and physical collage intersection, defined by high-contrast black and white textures, corrupted data forms, and classical/geometric elements.
**Keywords:** Glitch Brutalism, Cyberpunk Punk, Neo-Grunge, Post-Digital Collage, Raw Stipple.

## 2. Semantic Roles & Usage
* **primary-background:** `#FFFFFF` (Pure White). Forms the brutalist zone arena.
* **primary-glitch:** `#000000` (Pure Black). Used for all corrupted data blocks, text snippets, and wireframes.
* **heading-font:** `VT323`. Represents distressed digital text.
* **body-font:** `Space Mono`. Used for structural and instructional text.

## 3. The Open Standard for AI
This file format combines machine-readable YAML frontmatter with human-readable markdown prose. By defining design tokens as semantic roles alongside the "why" of design decisions, it serves as a unified context document to ensure AI coding agents produce visually consistent and on-brand UIs.
